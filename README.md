### 사용법
<img width=300 src=save.png>

<img width=400 src=save_type.png>

일단 ist 파일을 날개셋에 불러온 다음 XML 파일로 저장합니다.

<img width=280 src=select.png>

[ngconverter.xnu.kr] 에서 "자판 배열" 버튼을 눌러 자판 배열을 선택한 후 적용합니다.

<img width=400 src=convert.png>

"변환" 버튼을 눌러 저장한 XML 파일을 불러온 다음 다운로드되는 XML 파일을 저장합니다.

<img width=300 src=open.png>

<img width=400 src=open_type.png>

날개셋 제어판으로 다시 들어가 아까 다운로드한 파일을 열면 됩니다.
